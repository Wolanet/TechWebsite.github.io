Web Server Compromise — From a Public-Facing RCE to a Cobalt Strike Beacon

A public-facing IIS application was exploited through a known RCE (CVE-2019-6714), dropping a Cobalt Strike beacon that ran via DLL side-loading of a legitimate signed Java binary. The actor escalated to SYSTEM, built Windows-service and WMI persistence, and beaconed to a C2 domain masquerading as Microsoft Azure — contained by the EDR's managed threat-hunting team.
